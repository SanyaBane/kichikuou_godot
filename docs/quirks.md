# Quirk register

A **quirk** is behaviour of the original game that a modern designer would likely call a bug or an
oddity — a slip in the scenario script, an odd design decision, or an artefact of the System 3 /
xsystem35 engine — and that the port **reproduces on purpose**. The port follows the original in
every one of them; this register exists so that some can later be offered as optional fixes
(default off). Nothing here is fixed today, except STR-10's interface (owner's decision 19).

Rules:

- Every quirk has a stable **ID** (`BFL-03`, `ENG-02`, …): never renumbered or reused; a quirk
  that turns out not to exist is marked *withdrawn*, not deleted. Code marks the reproducing
  lines with `// QUIRK: <ID>`; specs and surveys cite the ID. Existing markers still cite the
  spec refs they were written with (`Q-3`, `02 Q11`, `§5.4 / Q11`, …) — those refs are given in
  parentheses after each ID so a grep for either finds the entry.
- A quirk found while porting is added here first (next free number in its area), then cited
  from the code and the spec ([porting-conventions.md](porting-conventions.md)).
- Only behaviour of the original belongs here — not documentation notes and not our own porting
  decisions. Purely visual layout oddities are listed only when they change what the player can
  do or meaningfully see.

Columns:

- **What the original does** — the behaviour, concretely.
- **Effect on play** — what a player can notice, or "state only" / "RNG only" when only memory
  or the random sequence differs.
- **Kind** — `bug` (the script evidently does not do what it means), `odd design` (deliberate or
  harmless but surprising), `engine artefact` (follows from System 3 / xsystem35 semantics),
  `dead code` (unreachable or write-only), `unverified` (a hypothesis marked [I]/[G] or an open
  question in the source; confirm by a capture before relying on it).
- **Where** — script `FILE.ADV:line`, spec section (`01` = [battle/01-flow.md](battle/01-flow.md),
  `02` = [battle/02-resolution.md](battle/02-resolution.md), `03` = [battle/03-rng-order.md](battle/03-rng-order.md),
  `screen` = [battle/screen-layout.md](battle/screen-layout.md), `bREADME` = [battle/README.md](battle/README.md);
  `main`, `commands`, `nations`, `dungeon`, `data`, `events`, `ikami`, `w4`, `gallery` = `strategy/survey-*.md`, `sREADME` =
  [strategy/README.md](strategy/README.md); `golden-tests`, `spike-findings`, `porting-conventions` = the docs of
  those names; `#n` = item n of a numbered list), and the port file
  when the behaviour is already ported (file names as of 2026-10-08; grep the ID or the marker
  ref for the exact line).
- **Fix** — candidate for an optional fix: `yes`, `maybe`, or `no` (pure internals, or a fix
  would shift balance in ways not worth it), with the reason when it is not obvious.
