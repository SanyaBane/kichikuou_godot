# Page classes for the golden-test harness (XSYS35_GOLDEN_CLASSES); see docs/golden-tests.md,
# "Harness configuration". UTF-8.
#
#   inner|pick FILE ...      before the first group: defaults of every group
#   group NAME [DIR]         starts a group (its own class table); its captures go to the
#                            subfolder DIR of the output folder (default NAME; "." = the folder)
#   root FILE ...            page-call roots: a call into FILE starts a capture
#   root FILE@ADDR           label root: arriving at hex address ADDR of FILE starts one
#   inner|pick FILE ...      the group's classes
#
# Roots are inner to their own group. Every file a group does not list is a hook: memory is
# dumped around calls into it and nothing inside is logged. A call into a root starts a capture
# unless an open capture of the same group logs that call as an inner one.
